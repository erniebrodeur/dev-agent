# Pilot

Pilot is a Codex plugin for disciplined, evidence-driven software development.

It provides reusable workflows for project activation, context recovery, planning, focused implementation, troubleshooting, Git status and commits, repository utilities, and user-authorized security checks.

## Start

After installing Pilot, invoke:

```text
$activate
```

Activation loads Pilot's development policy for the current task and recovers the repository's current state without changing project files.

See the [repository](https://github.com/erniebrodeur/pilot) for installation, development, and source information.

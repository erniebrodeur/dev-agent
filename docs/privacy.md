# Privacy

Last updated: August 8, 2026

Pilot does not operate a hosted service or data backend. The distributed plugin contains local instructions and assets, and does not independently collect personal information, run analytics, set cookies, or transmit telemetry.

Pilot runs within Codex. OpenAI and any tools or third-party services you choose to use may process data under their own privacy policies. The Pilot contributors do not control those services.

This documentation is hosted by GitHub Pages. GitHub may process technical information, including visitor IP addresses, as described in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Changes to this policy will be published on this page.
